## ✨ Key Features

> [!NOTE]
> An ultra-fast, feature-packed Telegram file renamer bot engineered to handle massive file queues and files up to **4GB** with zero bottlenecks.

- ⚡ **High-Speed Processing:** Lightning-fast file downloading, renaming, and uploading pipeline.
- 📦 **4GB File Support:** Effortlessly process files up to 4GB utilizing Telegram Premium String Sessions.
- 🖼️ **Permanent Custom Thumbnails:** Set, preview, and update persistent custom file thumbnails.
- 🏷️ **Dynamic Prefixes & Suffixes:** Automatically prepend tags or append custom labels to target filenames.
- 📝 **Custom Captions:** Create fully personalized file captions with HTML/Markdown formatting support.
- 🔒 **Force Subscribe (F-Sub):** Require users to join specific Telegram channels prior to using the bot.
- 💎 **Premium Membership & Free Trials:** Integrated automated trial activation and multi-tier subscription controls.
- 🛠️ **Custom Media Metadata:** Inject custom title, author, and audio/video stream tags into files.
- 🛡️ **Comprehensive Admin Suite:** Global broadcasting, ban/unban moderation, and real-time server activity logging.
- 🌐 **Cloud Native:** Ready for instant 1-click deployment on Koyeb, Render, Railway, Heroku, or VPS environments.

## ⚙️ Environment Variables

| Variable | Status | Description |
| :--- | :---: | :--- |
| `BOT_TOKEN` | `Required` | Telegram Bot Token obtained from [@BotFather](https://t.me/BotFather) |
| `API_ID` | `Required` | Telegram Application API ID from [my.telegram.org](https://my.telegram.org) |
| `API_HASH` | `Required` | Telegram Application API Hash from [my.telegram.org](https://my.telegram.org) |
| `ADMIN` | `Required` | Telegram User ID(s) of Admin(s) (separate multiple IDs with a space) |
| `DB_URL` | `Required` | MongoDB Database connection string from [MongoDB Atlas](https://cloud.mongodb.com) |
| `DB_NAME` | `Required` | MongoDB database collection name *(e.g., `Adv-RenameBot`)* |
| `FORCE_SUB` | `Optional` | Username of channel for Force Subscribe *(without the `@` symbol)* |
| `LOG_CHANNEL` | `Optional` | Telegram Channel ID for logging bot activity *(leave empty if not needed)* |
| `STRING_SESSION` | `Optional` | Pyrogram String Session *(Mandatory for handling **4GB** file sizes)* |
| `START_PIC` | `Optional` | Direct image URL to display on the `/start` command |

> [!TIP]
> **4GB File Handling:** If `STRING_SESSION` is omitted, the bot defaults to standard Telegram user limits (**2GB** max per file).

## 🤖 Bot Commands

<details open>
<summary><b>👤 User Commands</b></summary>
<br>

| Command | Action |
| :--- | :--- |
| `/start` | Check bot status and ping response |
| `/plans` | Explore available premium subscription plans |
| `/myplan` | View your active membership and quota details |
| `/view_thumb` | Display your currently saved custom thumbnail |
| `/del_thumb` | Remove your custom thumbnail |
| `/set_caption` | Set a persistent custom caption for renamed files |
| `/see_caption` | Preview your existing custom caption |
| `/del_caption` | Delete your active custom caption |
| `/metadata` | Configure and manage custom file metadata tags |
| `/set_prefix` | Configure a custom prefix for output filenames |
| `/see_prefix` | View the currently applied filename prefix |
| `/del_prefix` | Remove the configured filename prefix |
| `/set_suffix` | Configure a custom suffix for output filenames |
| `/see_suffix` | View the currently applied filename suffix |
| `/del_suffix` | Remove the configured filename suffix |

</details>

<summary><b>👑 Admin Commands</b></summary>
<br>

| :--- | :--- |

| `/remove_premium` | Revoke premium status from a user |

| `/unban` | Unban a previously blacklisted user |
| `/banned_users` | Retrieve a list of all currently banned users |
